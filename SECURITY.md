# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для последней версии Soundsave.

| Версия | Поддержка |
|--------|-----------|
| 2.x    | да        |
| 1.x    | нет       |

## Сообщение об уязвимости

Не создавайте публичный GitHub Issue для уязвимостей. Используйте
[GitHub Private Vulnerability Reporting](https://github.com/northis/soundsave/security/advisories/new).

В отчёте укажите:

* версию (`soundsave --version`) и версию Python;
* операционную систему;
* шаги воспроизведения;
* возможное влияние;
* предложение по исправлению, если есть.

Не прикладывайте токены, содержимое `.env` и персональные данные.

## Что считается уязвимостью

* выполнение произвольного кода при обработке файлов архива;
* выход за пределы `TARGET_DIR` при замене или резервном копировании;
* утечка токенов в логи или отчёты;
* подмена скачанного файла без проверки.

Проблемы сопоставления треков (например, замена на live-версию) — это баги
качества, а не уязвимости; сообщайте о них через обычный Issue.
