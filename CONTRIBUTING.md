# Участие в разработке

Спасибо за интерес к Soundsave. Проект небольшой, поэтому процесс простой.

## Окружение

Нужен Python 3.10+.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -e ".[dev]"
```

## Проверки

```bash
pytest                  # тесты
ruff check .            # линтер
ruff format --check .   # форматирование
```

Перед отправкой изменений убедитесь, что все три команды проходят.

## Что можно улучшить

* новые провайдеры каталога (кроме Zvuk) через протокол
  `soundsave.providers.base.MusicProvider`;
* улучшение сопоставления треков и обработка `ambiguous`-случаев;
* поддержка других форматов архива;
* документация и примеры.

## Pull Requests

1. Создайте ветку от `master`.
2. Добавьте тесты на новое поведение.
3. Опишите в PR, что и зачем изменено.
4. Убедитесь, что CI зелёный.

Не коммитьте `.env`, токены, скачанные треки и файлы из `.soundsave/`.
